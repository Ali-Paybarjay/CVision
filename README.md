# CVision

**Every application, made to fit.**

A job-application app for the UK. Upload your CV, paste a job ad, and get a tailored CV and cover letter. Paste. Tailor. Apply.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
