# CVision. Brand Guide

**CVision · working name**
Brand foundation, visual identity and voice

> **Every application, made to fit.**
> AI job-application app for the UK. Paste a job ad. Get a CV matched to it.

Version 2.2 · 27 October 2026

**New in version 2.2:** step 1 of the plan becomes “Build your profile.”, so people with no CV to upload can fill in their details. Version 2.1 renamed the product CVision. Version 2 made a light palette the primary palette, with a dark palette as its counterpart for dark mode; both replace the version 1 palette.

---

## 01 Brand foundation

### Hero
*The one customer the whole brand is about.*

**Anyone in the UK who wants a CV matched to the job they are applying for.**

- **What the hero wants:** get interviews for roles that match their experience.
- **Who we picture:** no single persona. The product stays open to everyone applying for jobs in the UK, so examples and imagery should vary.

### The problem
*One root cause, felt at three levels.*

**The villain:** application fatigue: so many applications that quality drops with each one.

| Level | What it feels like |
|---|---|
| External | They need to apply for lots of jobs quickly, and each one needs a tailored CV and cover letter. |
| Internal | Frustration: “I keep applying and hear nothing back.” |
| Philosophical | Looking for work shouldn’t mean losing weeks to paperwork. |

### Our guide role
*The brand is the guide, never the hero.*

- **Empathy:** We know job hunting can feel like a second full-time job, and it’s hard to keep going when nobody replies.
- **Proof of competence:** Every line in your CV traces back to something you told us. Nothing invented. *(Add real results from pilot users once we have them.)*

### The plan
*Three steps, one outcome.*

1. **Build your profile.** Upload your CV or fill in your details. Everything we write comes from your profile and from what you tell us.
2. **Paste a job ad.** We find what the employer is asking for, and where your experience already matches.
3. **Get a tailored CV and cover letter.** Every change is highlighted, so you can check it before you download.

**Paste. Tailor. Apply.**

### Stakes and transformation
*Keep fear light.*

- **If they do nothing:** weeks lost rewriting the same CV over and over.
- **If it works:** a clear, calm plan for every application.

Sending CVs into the void → Applying with confidence

### Core message
*Used everywhere: site, bios, signatures, pitch.*

- **One-liner:** We help anyone applying for a job in the UK turn any job ad into a tailored CV and cover letter in minutes, so they can get interviews.
- **Tagline:** Every application, made to fit.

*Light is primary; dark mirrors it.*

Every colour has a job. The light palette is the default for the app, the site and documents. The dark palette uses the same roles in the same proportions, for people whose device is set to dark mode. Design with roles, not hex values, so both modes stay in step.

- Add colours outside this palette.

### Colour tokens for the app
Name colours by role in code, so one set of components works in both modes. The dark values apply when the device is set to dark, unless the person chooses light.

```css
:root {
  /* CVision Light (default) */
  --color-canvas: #F2F5F9;      /* Canvas: app background */
  --color-surface: #FFFFFF;     /* Paper: cards, fields */
  --color-emphasis: #0F2A47;    /* Ink: dark sections */
  --color-on-emphasis: #FFFFFF;
  --color-text: #0F2A47;        /* Ink */
  --color-text-muted: #5B6B7F;  /* Slate */
  --color-line: #D5DDE6;        /* Line */
  --color-accent: #167480;      /* Teal */
  --color-cta: #FF7A5C;         /* Coral */
  --color-on-cta: #0F2A47;      /* Ink */
  --color-fit: #E3F2F3;         /* Fit */
  --color-fit-bar: #167480;     /* Teal */
  --color-warning: #9A5B00;
  --color-warning-bg: #FFF3D6;
  --color-error: #B42318;
  --color-cv-paper: #FFFFFF;    /* CV preview, both modes */
  --color-cv-ink: #0F2A47;
}

@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    /* CVision Dark */
    --color-canvas: #0B1724;    /* Night */
    --color-surface: #13253A;   /* Harbour */
    --color-emphasis: #1B3049;  /* Raised */
    --color-on-emphasis: #E2EAF3;
    --color-text: #E2EAF3;      /* Chalk */
    --color-text-muted: #93A5B9;/* Mist */
    --color-line: #2A3F57;      /* Edge */
    --color-accent: #42B9C3;    /* Lagoon */
    --color-cta: #FF7A5C;       /* Coral */
    --color-on-cta: #0B1724;    /* Night */
    --color-fit: #10393F;       /* Fit Night */
    --color-fit-bar: #42B9C3;   /* Lagoon */
    --color-warning: #F4B860;   /* Amber */
    --color-warning-bg: #3B2A0F;
    --color-error: #FF8597;     /* Rose */

}
/* Repeat the dark block under :root[data-theme="dark"] for a manual switch. */
```

In Tailwind, point each colour at its variable (for example `canvas: 'var(--color-canvas)'`), so components switch mode without `dark:` variants.

## 03 Verbal identity

### Brand voice
*Direct, efficient, sharp.*

- **Direct:** fast and matter-of-fact. Get to the point.
- **Efficient:** outcome first. Minutes, not weeks.
- **Sharp:** expert and serious. People applying for jobs prefer expertise to friendliness.

| From | | To (where we sit) |
|---|---|---|
| Friend | ●●●●○ | **Expert authority** |
| Playful | ●●●●○ | **Serious** |
| Warm and reassuring | ●●●●○ | **Fast and matter-of-fact** |

### Key messages
1. We know job hunting can feel like a second full-time job, and it’s hard to keep going when nobody replies.
2. Every line in your CV traces back to something you told us. Nothing invented.
3. A clear, calm plan for every application.
4. From sending CVs into the void, to applying with confidence.

### Language rules
- **Naming the user’s situation:** positively, as “your next chapter”. Never use the word “redundant” in headlines.
- **Talking about AI:** outcome first, AI as the how. The pitch must still show the AI clearly.
- **Never write:** guaranteed · dream job · beat the bots · hack the ATS · revolutionary · 10x · effortless
- **UK English everywhere:** colour, tailored, organisation.

## 04 Brand applications

### Calls to action
*One direct button, repeated on every page.*

- **Direct:** “Get started free”. The app is free in the first stage. The wording can be revisited when pricing is added.
- **Transitional:** “Free 2-minute CV check”. “Is your CV ready for UK employers?”

### Our Honest CV Promise
*Four promises we keep.*

- **Nothing invented:** We never invent experience you don’t have. Every claim comes from your CV and what you tell us.
- **You approve everything:** You review and approve everything. We never apply on your behalf.
- **Your data is yours:** Download or delete it any time.
- **Sounds like you:** We write from your own words, so it sounds like you, not a template.

### The name
*CVision: CV and vision in one word.*

Always write it as CVision: capital C and V, with no space or hyphen. The wordmark adds the Coral full stop; running text doesn’t.

⚠ **Before the name is final**
- In the US, CVISION is a registered trademark for imaging software (Class 9), now owned by Foxit Software. Check the UK trademark register (IPO), the domain and social handles before launch.
- “Nothing invented” and “Sounds like you”: the AI engine team confirms they hold by demo day.
- “Your data is yours”: the app build team confirms full deletion (UK GDPR) by demo day.
