# Tailor templates

The blank layouts the tailored CV and cover letter follow. No real data.

- `cv-template.pdf`: section order and layout, built in `src/features/tailor/tailored-cv.ts` and `export.ts`.
- `cover-letter-template.pdf`: letterhead and three-paragraph shape, built in `prompts/tailor-cover-letter.md` and `src/features/tailor/letter-state.ts`.
- `skills-reference.jpg`: skill families and action verbs, kept in `src/features/tailor/big-six.ts`.

The templates are in US English; the app writes UK English ("CV", "organisation", "Yours sincerely").
