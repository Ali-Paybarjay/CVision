مرضیه · صفحهٔ تمرین مصاحبه: پرسش، جواب، نمره و بازخورد.

- `/interview?job=<id>`: صفحهٔ اصلی برای یک آگهی کاربر؛ بدون `job` فهرست آگهی‌ها را نشان می‌دهد، با تاریخ و نمرهٔ آخرین تمرین کنار هر شغل. اگر مرورگر چیزی برای این شغل ندارد و حساب گزارشی دارد، صفحه اول «Your last practice» را نشان می‌دهد؛ «Practise again» به «How it works» می‌رود و دوباره به همان گزارش برنمی‌گردد. تصمیمش با `openingView` در `src/features/interview/engine/session.ts` است (#206).
- `/interview/api`: API صفحهٔ اصلی. مرورگر فقط شناسهٔ آگهی را می‌فرستد و متن آگهی و رزومه روی سرور خوانده می‌شود.
- `/interview/lab`: صفحهٔ آزمایشگاه برای برنامه‌نویس‌ها (فیکسچرها و پنل دیباگ)، روی سایت اصلی نیست.
- `_practice/`: بخش‌های مشترک صفحهٔ اصلی و آزمایشگاه (روند مصاحبه، گزارش بازخورد، ذخیره در مرورگر).
