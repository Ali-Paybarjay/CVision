علی · کد مشترک همه: شکل داده‌ها، دسترسی به هوش مصنوعی (askModel)، برند، اجزای UI و آمار. فقط با هماهنگی تیم عوض شود.

- `clean-text.ts`: تابع `cleanModelText(text)` نویسه‌های نامرئی را از متنی که به مدل می‌رسد پاک می‌کند: zero-width، BOM، soft hyphen، کنترل‌های bidi، tag characterها و variation selectorهای U+E0100 تا U+E01EF. پرچم انگلستان، اسکاتلند و ولز سالم می‌ماند، U+2028 و U+2029 خط تازه می‌شوند و متن در آخر NFC می‌شود. `{ text, counts }` برمی‌گرداند: تعداد هر دسته، به‌علاوهٔ `tamperSigns` برای نشانه‌های دست‌کاری. آن را از `@/shared/clean-text` import کنید، نه از `@/shared/ai`: این ماژول `server-only` ندارد و در مرورگر هم کار می‌کند (#68).
