علی · کد مشترک همه: شکل داده‌ها، دسترسی به هوش مصنوعی (askModel)، برند، اجزای UI و آمار. فقط با هماهنگی تیم عوض شود.

- `web/fetch-page.ts` (#278): ‏`fetchPublicPage(link)` یک صفحهٔ وب عمومی را از لینکی که کاربر داده می‌خواند و متن خواندنی‌اش را برمی‌گرداند، با `title` و `url` نهایی؛ اگر صفحه `JobPosting` ِ schema.org با شرح داشته باشد، فقط همان می‌آید (عنوان، کارفرما و شرح، یک خط برای هر بند) تا آگهی دو بار نیاید؛ بی شرح، عنوان آن و بعد متن صفحه. جواب `truncated` هم دارد. محافظ‌های سمت سرور (SSRF): فقط http و https روی پورت ۸۰ و ۴۴۳، بدون نام کاربری و رمز در لینک، و هیچ‌وقت localhost، شبکهٔ خصوصی، link-local (آدرس metadata ابر) یا multicast؛ هم برای خود لینک و هم بعد از هر redirect (حداکثر ۳). سقف ۱۰ ثانیه و ۲ مگابایت، و فقط `text/html`. در شکست یکی از این دلیل‌ها را می‌دهد: `invalid-url`، `blocked` (سایت اجازه نمی‌داد یا ورود می‌خواست، مثل LinkedIn)، `not-found`، `too-slow`، `too-large`، `not-a-page`، `no-text` (صفحه متن خواندنی ندارد، مثل صفحه‌ای که فقط با JavaScript ساخته می‌شود) و `failed`. هر کسی که لینکی از کاربر را باز می‌کند از همین استفاده کند، نه از `fetch` ِ خودش. محدودیت شناخته‌شده: DNS rebinding بین بررسی و اتصال؛ بستنش با `node:http`/`node:https` و یک `lookup` که آدرس لحظهٔ اتصال را چک کند ممکن است، بی وابستگی تازه، ولی روی Vercel فعلاً لازم نیست.
- `clean-text.ts`: تابع `cleanModelText(text)` نویسه‌های نامرئی را از متنی که به مدل می‌رسد پاک می‌کند: zero-width (همراه U+034F و U+180E)، BOM، soft hyphen، کنترل‌های bidi، tag characterها، variation selectorهای U+E0100 تا U+E01EF، پرکننده‌های Hangul (U+115F، U+1160، U+3164، U+FFA0) و نشانه‌های interlinear annotation (U+FFF9 تا U+FFFB). پرچم انگلستان، اسکاتلند و ولز سالم می‌ماند، U+2028 و U+2029 خط تازه می‌شوند و متن در آخر NFC می‌شود. `{ text, counts }` برمی‌گرداند: تعداد هر دسته، به‌علاوهٔ `tamperSigns` برای نشانه‌های دست‌کاری. آن را از `@/shared/clean-text` import کنید، نه از `@/shared/ai`: این ماژول `server-only` ندارد و در مرورگر هم کار می‌کند (#68).
